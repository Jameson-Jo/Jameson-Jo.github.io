# jameson-jo.github.io

Personal engineering portfolio for Jordan Jameson, aerospace engineering student at San Diego State University.

Covers high power solid fueled rocketry work: vehicle design, OpenRocket and MATLAB simulation, dual deployment avionics, structural and flutter analysis, and flight results including a written failure analysis.

**Live site:** https://jameson-jo.github.io

## Contents

| Project | Status |
| --- | --- |
| Queen Caline, 54 mm minimum diameter K class vehicle, Mach 1.42 predicted | In design, December 2026 target |
| Performance 2, two stage sub minimum diameter vehicle, Mach 3.3 target | Section lead, Rocket Project SDSU |
| Encore avionics bay, two stage vehicle | Flown May 2026 |
| Katana, 4 in airframe on a 54 mm motor | Flown, recovery failure analysis |
| ARCAS, first high power vehicle | Flown December 2025 |

## Stack

One static `index.html`. No build step, no framework, no dependencies beyond a Google Fonts stylesheet. Served by GitHub Pages from the repository root.
